## 1. 무엇을 했나

팀 사본 Qurious를 강사님 `lumina-invest` 원본 최신본(`6d91401`, 2026-09-14)에 맞췄다.
모의투자(paper trading)·LEAN 백테스트·Open API가 새로 들어왔다.
동시에 AWS 인프라 파일 138개와 앱 코드의 AWS 연동(Bedrock·SageMaker·Comprehend·S3·boto3)을 걷어냈다.
출발점을 정리하는 작업이라, 2·3차 설계 논의는 이 상태를 기준으로 한다.

## 2. 왜 했나

- **2·3차 담당 강사님이 바뀌어** `learning/th*` 자료가 기준이 됐다.
- Qurious 사본을 원본과 대조해 보니 원본에만 있는 파일이 14개, 내용이 다른 파일이 10개였다.
  빠진 기능이 하필 **모의투자와 백테스트**라, 이대로 분석하면 "모의투자 API를 안 쓴다" 같은 틀린 결론이 나온다.
- **비용은 팀원 자비**다. AWS 코드가 남아 있으면 분석·논의 범위가 넓어진다.

## 3. 어떻게 했나 — 고른 것과 버린 것

| 선택지 | 결과 | 이유 |
|---|---|---|
| 사본 그대로 두고 원본 퍼머링크로 분석 | 버림 | 이슈마다 두 저장소를 오가게 된다 |
| **최신본 반영 + AWS 인프라만 제거** | 버림 | 앱 연동은 자격증명이 없으면 조용히 꺼져 안전하지만, 코드에 남아 분석 범위를 넓힌다 |
| **최신본 반영 + 인프라·앱 연동 모두 제거** | **고름** | 설계 주간이라 실행 검증이 필요 없다는 판단(사용자 결정) |
| `onprem.md`·`pipeline.md`까지 제거 | 버림 | AWS 문서가 아니다. 온프레미스·데이터 파이프라인 설계서는 오히려 필요하다 |
| README IaC 비교 노트 제거 | 보류 | 일반 학습 노트라 남기고, README 전면 개정(A15)에서 다룬다 |

로보 어드바이저 점수에서는 **배치학습 점수(S3)와 뉴스 감성(Comprehend) 성분이 빠지고**
샤프비율 + AI 예측만 남는다. 응답의 `batch_training`·`news_sentiment` 필드도 뺐는데,
그 전에 `public/`에서 두 필드를 쓰는 곳이 **0건**인지 검색으로 확인했다.

## 4. 어떻게 확인했나

- 원본 대조: `.git` 제외 전 파일 MD5 비교 — Qurious 266개 / 원본 280개 / 원본에만 14 / 내용 차이 10 / Qurious에만 0
- AWS 흔적 재검색(`app/` `public/` 설정 파일): 남은 것은 "제거했다"는 주석 3줄뿐
- `python -m compileall -q app alembic` 통과 (문법만)
- **앱 기동·API 호출·테스트는 미실행** — 미측정

## 5. 막힌 것 · 남은 것

- **main에 직접 push했다가 되돌렸다.** 상위 모노레포 규칙(main 직커밋)을 팀 저장소에 그대로 적용한 실수다.
  force push 대신 `git revert`(`10a69ef`)로 되돌리고 같은 변경을 이 PR로 다시 올렸다.
- AWS 참조 검색이 결과 100개 파일에서 잘려 한 번에 전수가 안 됐다 → 경로를 좁혀 다시 찾았다.
  `lambda` 검색어는 파이썬 `lambda` 키워드까지 잡아 오탐이 많았다.
- 남은 것: LEAN docker 모드 실행(이미지 약 14GB), alembic `0002` 적용 확인, README 전면 개정, docs 폴더 구조 정비, `.env.prod` 추적 해제

## 6. 배운 것

- **사본은 원본을 따라가지 않는다.** 복사한 날 이후의 원본 커밋은 해시로 대조해야 보인다.
- **상위 규약과 저장소 규약은 다를 수 있다.** 커밋 전에 그 저장소의 규약을 먼저 확인한다.
- "자격증명이 없으면 꺼진다"는 코드는 비용은 0이지만 **읽는 비용**은 0이 아니다.
